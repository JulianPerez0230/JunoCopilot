# Class records

This directory stores dated records of real classes. A class may reference more
than one topic and must preserve its provenance.

Class records are source notes, not learning evidence. Link professor emphasis
to the relevant `TOPIC.md`, and record declared difficulties as context in
`UNDERSTANDING.md`. Only demonstrated explanations, exercises, or assessments
belong in `evidence/`.

Use `YYYY-MM-DD-short-title.md` for filenames and update `index.md` in the same
operation that creates or changes a class record.
