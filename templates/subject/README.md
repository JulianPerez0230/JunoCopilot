# Juno subjects

This directory contains learning-oriented memory for courses and subjects.
Subjects are not projects: they track topics, source materials, understanding,
errors, autonomy, and retention rather than deliverables and technical state.

Each subject lives in `subjects/<subject_id>/`. Each topic lives in
`subjects/<subject_id>/topics/<topic_id>/`.

`subjects/index.md` is the canonical subject inventory. Each subject keeps
dated class records under `classes/` with its own `classes/index.md`. Class
records may reference several topics and remain separate from learning evidence.
