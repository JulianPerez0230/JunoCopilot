# Project-scoped instructions

Read and follow `../../AGENTS.md` before working on this project.

- Treat this directory as the only active project.
- Recover project context from `project.yaml`, `PROJECT.md`, `STATUS.md`,
  `TODO.md`, and the current entries in `DECISIONS.md`.
- Read `sessions/index.md` when resuming work or checking for unfinished
  sessions. Read `inbox/index.md` when checking for provisional or unrouted
  project captures.
- Keep both indexes synchronized when creating a session record or changing a
  capture state. A missing index means the inventory is unavailable, not empty.
- Do not read or modify sibling projects unless the user explicitly requests it.
- Keep technical work incremental and follow the central approval and block
  closure rules when updating canonical memory.
