# General inbox index

This is the canonical inventory of general inbox captures. Juno must update the
corresponding row whenever it appends a capture, changes its review state, or
assigns a canonical destination.

The original message remains in the referenced daily file. This index stores
only enough information to find and reconcile captures without scanning every
daily file.
